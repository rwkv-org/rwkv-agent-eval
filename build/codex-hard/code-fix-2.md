优先补“题面合同→最小反例/真值表→最小修改→运行原测试→逐条修复失败”的短轨迹，重点覆盖成功后登记、失败原样传播、深拷贝隔离、逆序补偿、零句柄和重入。
第二类是cmd-error（5题）：用不存在的旧文本反复替换、替换未命中仍继续、CommonJS混写ESM，或由sed的&和引号引入新错误。
补“编辑失败→重读精确行→缩小替换→检查实际diff/匹配次数→运行指定测试”的恢复样本，禁止把工具completed、零项测试或无变化替换视为修复成功。

补两轮交接样本：保留已通过修复，重新提取新实参、路径、键名和答案格式，实际调用后序列化结果，再运行原测试和交接检查；失败只报告已观察事实，并保持tests/不变。
